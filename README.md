# Daily Task System

A full-featured daily task management app built with React + localStorage.

## Features
- Add tasks with title, priority (high/medium/low), and due date
- Daily task view — see only today's tasks
- Mark tasks complete / incomplete
- Streak tracking & progress stats
- Persistent storage via localStorage
- Filter by All / Active / Completed

## Getting Started

```bash
npm install
npm start
```

Or open `index.html` directly in your browser (no build step needed).

## Tech Stack
- React 18 (via CDN)
- Tailwind CSS (via CDN)
- localStorage for persistence
